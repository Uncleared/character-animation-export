Initial **prototype prerelease** of Character Animation Export for Blender and Unity.

### Download

Choose `CharacterAnimationExport-Prototype-0.1.0.zip` under **Assets** for both installers, a generated example and guides. The separate Blender ZIP and Unity `.unitypackage` are also available. GitHub's automatic source archives are for development.

### Start here

1. Install `CharacterAnimationExport-0.1.0.zip` in Blender Preferences → Add-ons → Install from Disk.
2. Open N → Animation Export, choose a rig and an external export folder, check clips, then Export Checked Clips.
3. Import the Unity `.unitypackage`, then open Tools → Character Animation Export and import `animation-export.json`.

[Full guide](https://github.com/Uncleared/character-animation-export#readme)

### Included

- Automatic NLA strip ranges with selected exports and combined body/prop baking.
- FBX All Actions and NLA Strips off; Bake Animation on.
- Unity root bake/full transform-mask defaults, isolated previews and native event editing.
- Stable clip identity on update, explicit duration review, and guarded archive/delete/recovery.

### Verification and limits

The original prototype passed 49 export checks on Blender 5.0.1 and 5.2.1, plus 14 native Unity EditMode checks on Unity 6000.1.7f1. Distribution checks also pass. GitHub CI checks distribution/pure Python logic, not native application behavior.

Native clip size remains a limitation; the representative Humanoid `.anim` was about 21.1 MB. Large-project usage scans can take minutes. Other versions, arbitrary procedural Blender features and final animator usability are not covered by these checks. Final human acceptance and independent implementation review are pending.

No production character or game assets are included.
