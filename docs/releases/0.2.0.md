The artist workflow is now **Export Folder → clip checkboxes → Export**.

- Export named FBXs directly into the selected folder, including Unity Assets.
- Derive ranges from authoring NLA strips and bake synchronized body/prop motion.
- Apply Bake Rotation/Y/XZ and the full prop mask automatically in Unity after one-time rig/Avatar setup.
- Preserve native FBX events, identities and references on routine updates. A shortened range warns and retains event data for correction.
- Install the optional Animation Event Editor independently.
- Keep existing libraries and generated clips through the legacy menu.

Download the complete CharacterAnimationExport-Prototype-0.2.0.zip, extract it, then install the inner Blender ZIP and Unity package. The event-editor package is optional.

This is a prototype prerelease for functional testing. See the README and validation document. Version 0.1.0 remains available.
