# 0.4.2 — Safer clip renames

Artists can change their mind about separate clip names. Returning to an earlier name reconnects the clip to its old FBX automatically. Reusing a file from a different removed animation asks first, because references and events on that file will apply to the new animation.

**Already on 0.4.1? Install only CharacterAnimationExport-0.4.2.zip in Blender.** The Unity importer and existing FBXs are unchanged, and no re-export is needed.
