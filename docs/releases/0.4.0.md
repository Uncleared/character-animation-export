# 0.4.0 — Lightweight separate FBXs

**Separate FBXs → Lightweight → Export.** Keep the same Folder to update existing files, events and references in place. Uncheck Lightweight to restore Full geometry. Preview with the full character prefab.

- Body, facial and animated prop data retained; staged FBXs validated before publication.
- Chosen preview prefabs persist across clip changes/reload; Generic motion roots are preserved.
- Compression defaults to Optimal with 0.01 rotation, 0.01 position and 0.5 scale error.
- Idle names enable Loop Time automatically, with per-clip exceptions.

Measured on 200 generated NLA clips: **1.58 GB → 0.80 GB (49.1% saved)**. [Full results](../BENCHMARKS.md). Both modes passed native animation comparisons and real Valencia gameplay checks.

Update both the Blender ZIP and Unity package. The separate event-editor package remains optional. [Short guide](../../README.md).

**Upgrade from 0.3:** existing folders receive the compression and Idle-loop defaults on installation. Differing native settings are replaced and cause a reimport. Disable Set Compression or Loop Idle Clips to keep subsequent native edits.

Independently reviewed by Claude Opus 5.5. Native Blender/Unity tests and game checks passed; no artist test, player build or headset result is claimed.
