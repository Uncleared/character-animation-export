Character Animation Export 0.2.0 — Prototype

BLENDER
Install the inner Blender ZIP: Preferences > Add-ons > Install from Disk.
In the 3D View: N > Animation Export.
Choose Export Folder (inside Unity Assets is supported), check clips, press Export.
Save the blend to remember the folder and clip choices.
Settings contains rig/props, scale/end bones and advanced options.

UNITY — ONCE PER CHARACTER
Import CharacterAnimationExport-Unity-0.2.0.unitypackage.
Select the export folder: Assets > Animation Import Settings.
Choose Generic, or Humanoid with the matching Source Avatar.
Bake Rotation/Y/XZ and the full prop mask default to ON.
Future FBXs import normally; no library or JSON import operation is needed.

EVENTS
Unity's native FBX Animations > Events editor remains available.
The optional AnimationEventEditor package adds Tools > Animation Event Editor.
It works independently on ordinary .anim and imported FBX clips.

Unchecking/removing sources does not delete existing FBXs.
Keep the automatically maintained AnimationExportData folder beside the FBXs.
Existing libraries: Tools > Legacy > Character Animation Library.

Guide/downloads: https://github.com/Uncleared/character-animation-export
