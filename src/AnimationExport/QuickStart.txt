Character Animation Export 0.3.0

BLENDER
Install the inner Blender ZIP and enable the add-on.
3D View: N > Animation Export.
Choose Folder inside Unity Assets > Combined FBX > File Name > check clips > Export.
Save the blend. Future updates: just Export.
NLA strips set the ranges automatically, including scaled fractional ranges.
Body, face and animated props are included in one FBX.

UNITY: ONCE PER CHARACTER
Install CharacterAnimationExport-Unity-0.3.0.unitypackage.
Select the export folder > Assets > Animation Import Settings.
Choose Generic, or Humanoid with the matching Source Avatar.
Bake Rotation/Y/XZ, full prop mask, original facing and XZ origin default ON.
Future exports import automatically. Update both packages together.

Unchecking a combined clip asks before removing it. Survivors keep events/references.
To swap a take: uncheck the alternate, then Settings > original clip's link button.
Separate FBXs remain available; unchecked separate files stay in place.
Keep the output folder together when handing it over. No manual JSON import.
To relocate: move the whole folder in Unity, then choose its new location in Blender.

EVENTS
Use Unity's native FBX > Animations > Events.
Optional independent package: Tools > Animation Event Editor.
Updates preserve event seconds; review cues when retiming the actual gesture.
